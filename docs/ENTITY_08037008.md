# Location-bound actor entity hierarchy at 0x08037008

## Scope

This document records the proven retail structure of the neutral `AActorEntity`-derived hierarchy beginning at `0x08037008`. The gameplay identity of these classes is not yet proven, so source names remain address/vtable-derived. The current source implementation is `include/entity_unk_08037008.hh` and `src/entity_unk_08037008.cc`.

## Base class

`UnkEntity37008` is a 0x44-byte abstract `AActorEntity` subclass with this proven tail layout:

| Offset | Type | Meaning |
| ---: | --- | --- |
| +0x30 | `ActorLocation *` | borrowed persistent location back-reference |
| +0x34 | `Box` | working/collision box |
| +0x3C | `u16` | value returned by virtual +0x34 |
| +0x3E | `u16` | runtime counter/state cleared by virtual +0x10 |
| +0x40 | `bool` | initialization/update flag |

The constructor at `0x08037008` calls `AActorEntity(game_object, location, 2, arg_3)`, stores `&location`, initializes the `Box` to zero, stores `arg_4` at +0x3C, clears +0x3E, and sets +0x40. The destructor at `0x08037048` writes `GetLocation()` back through `location_ref` before normal base destruction. This establishes two-way location persistence for the hierarchy.

The base vtable is retail `0x080E7328`. It adds pure virtual slots at +0x3C and +0x40. Recovered base virtual behavior includes:

- +0x0C `GetBox()`: a 14x14 box centered on x and two pixels above y.
- +0x10: if the +0x40 flag is clear, dispatch +0x3C, then clear +0x3E and call `AEntity::vfunc_10()`.
- +0x14: call `AEntity::vfunc_14()` and clear +0x40.
- +0x34: return the +0x3C halfword.
